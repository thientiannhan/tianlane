## 1. Scope & Primary Capability

The Tianlane Platform provides enterprise-grade project delivery governance for Logtechub, structured around:
1. Microsoft Teams SSO & Password Authentication with Admin Password Reset.
2. Three-tier hierarchy: `Project > Milestone > Task` with Odoo ERP ticket linking.
3. Interactive 273-day horizontal Timeline with sticky headers and off-screen jump anchors.
4. Multi-team organization with PM position management.
5. Cloudflare R2 Presigned S3 file storage (50 MB cap).
6. Streamable HTTP Model Context Protocol (MCP) JSON-RPC 2.0 server.

For complete requirements, schemas, and blast radius maps, refer to the canonical [tianlane-spec.md](../../tianlane-spec.md).
